## Description

Threat Arrows makes threat easier to read above enemy nameplates in **World of Warcraft: Forever**.

Choose from four artistic arrow styles: **Forged, Arcane, Sentinel and Wisp**. Customize secure, losing, lost and unknown threat colors with a circular color picker, brightness control and live preview. Arrows stay clean without numbers; the compact **Threat Watch** panel displays available threat percentages.

Use the draggable minimap shield icon to open settings or toggle Threat Watch. Move, resize and lock the panel, adjust opacity, and choose a maximum range-warning distance from **1–40 yards**, with a **10-yard default**. Settings are saved across reloads.

### Getting started

Install through CurseForge or extract the release ZIP into your game's `Interface/AddOns` folder. Enable Threat Arrows in the AddOns list and turn on enemy nameplates (normally **V**). Open settings using the minimap shield icon or **/ta options**.

- Left-click the minimap icon: settings.
- Right-click: show/hide Threat Watch.
- Drag the minimap icon: reposition it.
- /ta size 80: change arrow size.
- /ta opacity 65: change arrow opacity.
- /ta offset 30: adjust arrow position.

### Compatibility and limitations

Built for **WoW Forever 1.60.1 (interface 16001)**. Retail and other Classic versions are not currently claimed as supported. The addon is display-only: it does not target enemies, cast spells or send input. Range warnings do not change a spell's actual range. Threat and range depend on data exposed by the game client; unavailable or restricted results are shown as unknown. Only enemies with visible nameplates can appear. This is an initial beta; please report client-specific issues on GitHub.
